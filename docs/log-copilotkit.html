Usage: copilotkit init [options]
       copilotkit create [options]

Initialize a new CopilotKit project and connect it to a CopilotKit workspace
through Ops/Clerk before scaffolding. Reuses an existing CLI session or opens
browser sign-in when needed. Managed scaffolds use a project-scoped Intelligence
API key; local/self-hosted scaffolds retain legacy license setup when required.

Aliases:
  create                 Alias of init

Options:
  -n, --name <name>      App name (names the local app and its directory)
  -f, --framework <fw>   Agent framework (prompted if omitted)
  -i, --intelligence     Deprecated no-op: Intelligence (durable conversations,
                         persistence, insights) ships with every supported
                         framework.
      --channel <what>   Pre-answer the managed Channel offer: slack, teams, or
                         none. With this flag the offer is never shown, so a
                         scripted run cannot land on a provider by mistiming a
                         keystroke. `none` declines it outright.

                         Accepted only for frameworks whose starter ships a
                         Channel host; run `copilotkit framework list` to see
                         which, and `copilotkit channels providers` for what each
